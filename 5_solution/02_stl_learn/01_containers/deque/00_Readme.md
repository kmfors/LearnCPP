
deque 全称：double-ended queue（双端队列）

- 在头部和尾部高效插入/删除元素的序列容器
- STL（标准模板库）的一部分，位于 <deque> 头文件

deque 特点：

- 随机访问：支持 [] 和 at() 访问元素
- 动态大小：自动管理内存
- 两端操作：在头尾插入/删除都是 O(1) 时间复杂度（重点）
- 中间插入/删除：相对较慢 O(n) 时间复杂度

存在争议：

- 插入可能使所有迭代器失效
- 除了在频繁在头部或尾部进行插入和删除操作外，deque比list和forward_list的性能更差

```cpp
std::deque<int> dq;

dq.size();      // 当前元素个数
dq.empty();     // 是否为空
dq.max_size();  // 最大可能大小

// 调整大小
dq.resize(10);       // 调整为10个元素，新增的为0
dq.resize(15, 5);    // 调整为15个元素，新增的为5

dq.shrink_to_fit();  // 请求减少容量（非强制）
```
